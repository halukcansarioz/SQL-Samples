Bu depo, **SQL Server** öğrenme sürecim boyunca geliştirdiğim çeşitli uygulamaları, pratikleri ve örnek sorguları içermektedir. SQL Server üzerinde temel ve ileri düzey veritabanı işlemlerini kavramak amacıyla oluşturulmuştur.

## 🎯 Proje Hakkında

Bu çalışma, ilişkisel veritabanı yönetimi ve SQL sorgulama yeteneklerini pratik etmek amacıyla hazırlanmıştır. Proje temel olarak şu konuları içerir:
1. **Temel Veritabanı İşlemleri (CRUD):** Veri ekleme (INSERT), okuma (SELECT), güncelleme (UPDATE) ve silme (DELETE) işlemleri.
2. **İlişkisel Veri Yönetimi:** Farklı tabloları birleştirerek (JOIN işlemleri) kompleks veri setleri oluşturma.
3. **Gelişmiş T-SQL Yetenekleri:** Alt sorgular (Subqueries), gruplama (GROUP BY) ve veritabanı objelerinin (Stored Procedures vb.) kullanımı.

Bu proje, veritabanı mimarisi ve SQL analizi konularında temel oluşturabilecek bir yapıdadır.

## 📂 Depo İçeriği

Bu projede yer alan temel bileşenler şunlardır:

* **`SQL-Kaynaklar/`**: SQL ile ilgili çeşitli kaynakların, örnek veritabanı yedeği dosyalarının (.bak) veya dokümanların bulunduğu klasör.
* **`SQLQuery1.sql` - `SQLQuery9.sql`**: Farklı senaryolara göre yazılmış ve adım adım zorlaşan örnek T-SQL sorgu dosyaları.

## 🛠️ Kullanılan Teknolojiler ve Araçlar

Projede aşağıdaki teknolojiler ve ortamlar kullanılmıştır:

* **Veritabanı Yönetim Sistemi:** Microsoft SQL Server
* **Sorgu Dili:** T-SQL (Transact-SQL)
* **Geliştirme Ortamı (IDE):** SQL Server Management Studio (SSMS) veya Azure Data Studio
